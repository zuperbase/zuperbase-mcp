# Contributing

Thank you for helping. This repository holds what people install in their AI app: the plugin, the skill and the
docs. The connector itself runs at Zuperbase.

- **Bugs and ideas:** open an issue. Say which AI app you use and what you asked.
- **Docs:** pull requests that fix setup steps for an AI app are very welcome; menus change often.
- **The skill and the tool and prompt lists** are kept in Zuperbase's main code and copied here on each release, so
  a pull request against them is read and then made there.

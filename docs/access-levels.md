# Access levels

You choose the level when you connect, and change it any time under **Settings › Connected AI apps › Change**.
Whatever the level, an app can never do more than the person who connected it.

| | Read only | Prepare drafts | Bookkeeper |
|---|:---:|:---:|:---:|
| Reports, statements, search, explanations | ✓ | ✓ | ✓ |
| Customers, vendors and items | | ✓ | ✓ |
| Draft invoices, bills and journals | | ✓ | ✓ |
| Keep source documents with drafts | | ✓ | ✓ |
| Post invoices, bills and journals, up to a limit | | | ✓ |
| Match and categorise bank lines, up to a limit | | | ✓ |
| Payments, filing returns, voids, closing periods, users, export | ✗ | ✗ | ✗ |

**Areas.** Each connection is limited to the areas you tick: sales, purchases, banking, journals, and reports.

**Bookkeeper.** Only an owner or admin can choose it. The limit applies to each document or bank line, in the base
currency; anything above it stays a draft (or an open line) for a person. The person's own approval limits,
maker-checker and locked periods still apply.

**First-time set-up.** When you allow it, a new connection may also fill in the business profile, tax registration,
bank accounts and invoice numbering, until the first entry is posted and for at most 7 days.

**Who may connect.** Owners always may and admins by default; anyone else only when an owner or admin allows them.
An owner can turn AI apps off for the whole organisation in one step.
